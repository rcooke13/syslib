# Systems Librarianship: Installing, configuring, and administering a library website and OPAC

## Project Overview
This project was developed for a graduate Systems Librarianship class and documents the installation, configuration, and administration of a library website and Online Public Access Catalog (OPAC).
This project uses WordPress for its content management system to create and manage the library website, and links to Koha, the the Integrated Library System (ILS), and Omeka, the digital repository, to manage library collections, cataloging, circulation, and the OPAC.

## Technologies Used
-**Koha**: Integrated Library System (ILS) and OPAC
-**Wordpress**: Library website content management
-**PHP**: A server-side scripting language that builds and powers the website
-**MySQL**: Manages the accounts and databases
-**Apache**: Web Server
-**Linux**: Operating system and Linux command line environment
-**Bash**: Shell scripting, task automation, and systems administration 

## Installation and Configuration 
The project involved:
1. Setting up the Linux server environment in a Google Instance, and coding.
2. Installing and configuring the Apache web server and the PHP scripting language.
4. Installing and configuring the MySQL relational database to build and manage user accounts and databases.
5. Creating catalog records in MySQL.
6. Installing and configuring Koha on a separate instance for library management and OPAC access.
7. Installing and configuring Wordpress and Omeka on the second instance for the library website and digital repository, respectively.
8. Connecting the library website and systems.
9. Deploying the local files to Guthub Pages.
10. Documenting the project in Markdown.

## Project Purpose
This project provided hands-on experience with library systems administration, web development, database management, and the deployment of an integrated library website and OPAC.
