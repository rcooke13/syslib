# Systems Librarianship: Coding, configuring, and administering a library website and OPAC

## Project Overview
This project was developed for a graduate Systems Librarianship class and documents the installation, configuration, and administration of a library website and Online Public Access Catalog (OPAC).

This project uses WordPress to manage the library website, and it links to Koha, the Integrated Library System (ILS), and Omeka, the digital repository. These systems together manage library collections, cataloging, circulation, and the OPAC.

## Technologies Used
- **Koha**: Integrated Library System (ILS) and OPAC
- **Wordpress**: Library's content management system
- **PHP**: A server-side scripting language that builds, powers, and gives dynamism to the website
- **MySQL**: Manages the accounts and databases
- **Apache**: Web Server
- **Linux**: Operating system and Linux command line environment
- **Bash**: Shell scripting, task automation, and systems administration

The project involved:

4. Installing and configuring the MySQL database to build and manage user accounts and databases.
5. Creating catalog records in MySQL.

## Project Purpose
This project provided hands-on experience with library systems administration, web development, database management, and the deployment of an integrated library system and OPAC.
